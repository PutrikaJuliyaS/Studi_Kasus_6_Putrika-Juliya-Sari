### penjelasan kode

1. program menggunakan format penyimpan json, jadi menggunakan import json

2. program menggunakan library os untuk mengecek apakah file ada atau tidak

3. kode function digunakan agar kode bisa dipanggil saat dibutuhkan

4. def simpan data: menyimpan dan membaca data json

5. def tampilkan data: untuk menjalankan pilihan menu 1. menggunakan conditional statement jika data nilai belum ada

6. def tambah data: untuk menjalankan pilihan menu 2. menginput nama, nim dan menggunakan kode while true jika input nilai bukan angka

7. kode append untuk menambahkan data baru kedalam simpan data

8. def menu: untuk memanggil menu. menu menggunakan looping dan conditional statement untuk memanggil function yang sesuai dan berhenti jika user memilih menu 3 (keluar)

9. terakhir, kode menu() untuk memanggil menu
